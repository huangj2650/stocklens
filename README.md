# StockLens · 股票分析体系

> **想自己开网页用？看 [使用指南.md](使用指南.md) —— 双击启动文件即可。**

一个本地运行的网页版股票分析体系，按四大板块组织：**金融热点新闻 / 市场热点 / 自选股 / 技术分析与选股**，覆盖 **A股 / 港股 / 美股** 三市场。

![preview](https://img.shields.io/badge/market-A股|港股|美股-blue) ![python](https://img.shields.io/badge/python-3.11-green)

## 快速开始

```bash
cd /workspace/stock-analyzer
python3 app.py --port 8000
# 浏览器打开 http://127.0.0.1:8000
```

## 四大板块

### ① 金融热点新闻
- 新浪财经 + 东方财富双源快讯聚合，按时间倒序、自动去重
- 可按来源筛选，点击跳转原文
- 侧栏市场情绪面板（涨跌家数/涨停跌停/情绪分级）+ 实时涨幅榜

### ② 市场热点
- 行业（49个）/ 概念（175个）/ 地域（31个）板块涨幅排行
- 点击板块查看成分股实时行情，一键加自选
- 成交额榜 / 涨幅榜 / 跌幅榜

### ③ 我的自选股
- 自选股表格：现价、涨跌额、涨跌幅、综合评分、信号
- 评分对比横向条形图
- 支持添加/移除，点击任意行跳转技术分析

### ④ 技术分析与选股
- 个股技术分析：K线(可叠加MA/BOLL)、成交量、MACD、KDJ、RSI 五图联动
- 综合评分仪表盘（趋势30+动量25+均线20+量能15+位置10）
- 可解释的盘面解读（逐条看多/看空理由）、支撑压力位
- **技术选股器**：7个预设策略一键扫描全市场
  - MACD金叉 / 均线多头 / 放量上攻 / 超跌反弹 / 强势趋势 / 高评分 / 突破新高
  - 两阶段筛选：快照预筛（流动性过滤）→ 逐只精算指标 → 按评分排序
  - 结果展示命中条件，可直接加自选

## 传统功能

| 模块 | 说明 |
|------|------|
| 行情快照 | 实时价格、涨跌幅、开高低收、成交额（A股/港股/美股） |
| K线图 | 近3月/半年/1年/2年 日K，可叠加 MA5/10/20/60 与 BOLL |
| 综合评分 | 0-100分 + 五档信号（买入/增持/观望/减持/卖出） |
| 关键价位 | 基于局部极值+均线的支撑位/压力位识别 |
| 基本面 | A股新浪财务指标（ROE/毛利率/增长率/负债率等），美股关键财务 |
| 大盘概览 | 上证/深证/创业板/沪深300/中证500 指数条 |

## 支持的代码格式

```
600519 / sh600519 / 600519.SH   A股（沪）
000001 / sz000001 / 000001.SZ   A股（深）
430047 / 830799                 北交所
00700 / hk00700 / 0700.HK       港股
AAPL / usAAPL                   美股
```

搜索框支持中文名称模糊搜索（如输入"茅台"）。

## 评分逻辑（可解释）

```
强烈看多 ≥ 80  →  信号：买入
65 ≤ 偏多 < 80  →  信号：增持
45 ≤ 中性 < 65  →  信号：持有观望
30 ≤ 偏空 < 45  →  信号：减持
强烈看空 < 30  →  信号：卖出
```

每个维度的加分/扣分都会在"盘面解读"面板逐条列出，例如：

- ✅ 看多：`放量上涨（量比 1.82），资金进场积极`
- ⚠️ 看空：`股价位于20日均线（1273.42）下方，短期承压`

## 数据源与稳定性

| 市场 | 主源 | 备源 |
|------|------|------|
| A股 | 新浪历史/快照（akshare） | 东财（未启用） |
| 港股 | 新浪历史/快照（akshare） | 日线兜底 |
| 美股 | Nasdaq 官方 API | yfinance → 日线兜底 |

- 内存 TTL + 磁盘双级缓存（`data/cache/`），上游临时不可用时自动降级返回最近缓存
- 所有请求带 3 次重试与指数退避

## 工程结构

```
stock-analyzer/
├── app.py                  # Flask 入口 + REST API
├── app/
│   ├── core/
│   │   ├── datasource.py   # 行情/基本面数据层（多源/缓存/降级/代码规范化）
│   │   ├── market.py       # 新闻聚合 / 板块热点 / 榜单 / 市场情绪
│   │   ├── screener.py     # 技术选股引擎（预设策略/两阶段筛选）
│   │   ├── indicators.py   # 技术指标（MA/EMA/MACD/KDJ/RSI/BOLL/ATR/OBV…）
│   │   └── scoring.py      # 评分与信号引擎
│   ├── templates/index.html
│   └── static/
│       ├── css/style.css
│       └── js/app.js       # 四板块切换 + ECharts 渲染 + 选股器交互
└── data/cache/             # 磁盘缓存（自动生成）
```

## API 一览

| 端点 | 说明 |
|------|------|
| `GET /api/news?limit=40` | 金融新闻聚合（多源去重） |
| `GET /api/hotspots?kind=industry` | 板块热点（industry/concept/region） |
| `GET /api/sector/stocks?label=hangye_ZL01` | 板块成分股 |
| `GET /api/rankings` | 涨幅/跌幅/成交额/换手率榜 |
| `GET /api/sentiment` | 市场情绪（涨跌家数/涨停数/情绪分级） |
| `GET /api/screener/presets` | 预设选股策略 |
| `GET/POST /api/screener` | 执行技术选股 |
| `GET /api/analyze?symbol=600519` | 个股行情+指标+评分+图表数据 |
| `GET /api/quote?symbol=00700` | 实时报价快照 |
| `GET /api/financials?symbol=600519` | 基本面指标 |
| `GET /api/search?q=茅台` | A股名称/代码搜索 |
| `GET /api/market` | 大盘指数概览 |
| `GET/POST/DELETE /api/watchlist` | 自选股管理 |
| `GET /api/health` | 健康检查 |
